# GPS and POI Search Issue Analysis

## Problem Summary
The app cannot find/search POIs correctly due to multiple interconnected issues.

## Root Causes Identified

### 1. Missing _citta.csv Files (Main Issue)
**Symptoms from logs:**
```
W OnlinePoi: HTTP 404 for https://raw.githubusercontent.com/pasqualelembo78/huntix-poi/main/italia/lazio/_citta.csv
W OnlinePoi: Failed to fetch _citta.csv for lazio
D OnlinePoi: Nessuna città per nessuna regione, fallbackPois
```

**Root Cause:**
The Python extractor (`extract_all_pois.py`) was designed to process only ONE region at a time (interactive mode), so most Italian regions (lazio, basilicata, campania, etc.) were never extracted to GitHub.

Only regions `puglia` and `valle_daosta` existed in the repository, but the app expects all 20 regions.

### 2. Interactive Mode Limitation
The original script used:
```python
choice = input(">>> Numero (1-20): ").strip()
```
This required manual selection of one region at a time.

### 3. Region Fallback Chain Failure
Even when location is in a valid region (e.g., basilicata), the app follows this logic:
1. Try main region (basilicata) → 404
2. Try adjacent region (campania) → 404
3. Fallback to hardcoded POIs (only 5 hardcoded POIs in Rome area)

Result: No real POI data available.

### 4. Large File Size Issue During Push
When trying to push data to GitHub:
```
remote: error: File global_pois.csv is 113.18 MB; this exceeds GitHub's file size limit of 100.00 MB
remote: error: GH001: Large files detected.
```
Solution: Removed `global_pois.csv` from the repository as it was not essential for app function.

### 5. City Slug Format Mismatch
**Issue:** City folder names use CAP+slug format (e.g., `70057_palese_ba`) while the app expects simpler slugs (e.g., `palese_ba`)

**Example from _citta.csv:**
```
41.124218,16.725321,70057 Palese (BA),70057_palese_ba,0,0,0,0,0
```

## Solution Implemented

### Script Modification (extract_all_pois.py):
1. Removed interactive `input()` prompt
2. Extracted region processing into `process_region()` function
3. Main loop now iterates through ALL regions automatically
4. Added CLI options:
   - `--region NUM` for single region processing
   - `--all` for batch processing all regions
   - `--no-push` to skip git operations

### Command to regenerate all regions:
```bash
python3 extract_all_pois.py --all --no-push
```
